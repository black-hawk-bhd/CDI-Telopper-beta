CDI-Telopper 2.0.0-beta.67 操作ガイド
Windows 10 / Windows 11（64ビット）

旧版を終了し、新しいZIPを別のフォルダーへ展開して CDI-Telopper.exe を起動してください。
フォルダー版と単一EXE版は、いずれも .NET 10.0.14 を同梱します。

【電文確認で地名の読みを見る】
「受信・過去電文確認」で地震電文を選び、「震度観測点（電文）」を開くと、
電文の地点名、読みを特定できた場合のルビ、震度が表示されます。
地震の細分区域と津波予報区のルビは、確認画面のページ本文に表示されます。
辞書は本体に同梱しています。出典は同梱の docs/data-sources.md を参照してください。
