CDI-Telopper 2.0.0-beta.75 操作ガイド
Windows 10 / Windows 11（64ビット）

旧版を通知領域のメニューから終了し、新しいZIPを別のフォルダーへ展開して
CDI-Telopper.exe を起動してください。この単一EXE版には .NET を同梱しています。
実行ファイル横に設定を保存している場合は、旧版の Settings フォルダーを新版へコピーしてください。

【OBS字幕にPNGを添える】
「出力」→「字幕と一緒に送出する画像」で、情報種別ごとにPNGを1枚登録できます。
位置と横幅を指定し、「保存して反映」を押してください。
画像は該当する字幕の表示中にOBSとブラウザープレビューに出ます。

【同梱の訓練XML】
「テスト」→「生データ・テストライブラリー」→「XMLフォルダーを一括登録」で
TrainingSamples フォルダーを選ぶと、気象庁のサンプルXML185件を登録できます。
登録後は情報種別と電文種別で絞り込めます。出典は TrainingSamples/README.md に記載しています。
