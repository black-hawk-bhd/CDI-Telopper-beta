CDI-Telopper 2.0.0-beta.76 操作ガイド
Windows 10 / Windows 11（64ビット）

旧版を通知領域のメニューから終了し、新しいZIPを別のフォルダーに展開してください。
実行ファイル横に設定を保存している場合は、旧版の Settings フォルダーを新版へコピーします。
CDI-Telopper.exe を起動してください。この単一EXE版には .NET を同梱しています。

【緊急地震速報の詳細表示】
「表示」→「ページと文字」で、予想最大震度・推定マグニチュードの表示を設定できます。
初期値はオフです。有効にすると、受信データに値がある項目をプレビューとOBSに表示します。
取消を受信すると、該当する速報は取消表示に切り替わります。

【火山情報の通知音】
「音声」→「火山情報」で、噴火警報・予報（VFVO50）と噴火速報（VFVO56）の音源を設定できます。

【同梱の訓練XML】
「テスト」→「生データ・テストライブラリー」→「XMLフォルダーを一括登録」で
TrainingSamples フォルダーを選ぶと、気象庁のサンプルXML185件を登録できます。
出典は TrainingSamples/README.md を参照してください。
