CDI-Telopper 2.0.0-beta.73 操作ガイド
Windows 10 / Windows 11（64ビット）

旧版を終了し、新しいZIPを別のフォルダーへ展開して CDI-Telopper.exe を起動してください。
フォルダー版と単一EXE版は .NET 10.0.14 を同梱します。

【緊急地震速報の継続報】
「表示」の「緊急地震速報の継続報で追加・更新された地域名をオレンジ色にする」をオンにすると、
同じ警報の前報から追加・更新された地域名を強調します。OBSの横型・縦型とアプリ内プレビューに対応します。

【震度速報と津波注意報・警報】
「表示」の「津波注意報以上の発表中は震度速報の定型注意文を省く」をオンにすると、
津波情報の表示が有効で、同じ地震の有効な注意報・警報を受信済みの場合に、
「念のため津波に注意してください。」の一文だけを省きます。地震IDで照合できない場合は表示します。

【震度観測点】
「フィルター」→「表示フィルター」の「気象庁以外の震度観測点を非表示」で、
Wolfx・気象庁XML・DMDATA.JP・AXISの気象庁電文にある、末尾が全角＊の観測点を詳細字幕から除きます。
Wolfxの地震字幕では、観測点の＊を説明する定型注記を省きます。

上記の3つの設定は初期値がオフです。設定後は「保存して反映」を押してください。
