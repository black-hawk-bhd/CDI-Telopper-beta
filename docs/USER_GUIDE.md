# CDI-Telopper 操作マニュアル

[English](USER_GUIDE_EN.md) | 日本語

対象は Windows x64 版の **2.0.0-beta.75** です。画面に表示される日本語の項目名で操作を案内します。[ダウンロード](https://github.com/black-hawk-bhd/CDI-Telopper-beta/releases/tag/v2.0.0-beta.75) / [変更内容](../RELEASE_NOTES_2.0.0-beta.75.md)

## インストールと更新

1. .NET同梱の単一EXE版のZIPを取得し、リリースに添付されたSHA-256と照合します。軽量版を選ぶ場合は、.NET 10 Desktop Runtime（x64、10.0.14以降の10.0系）をインストールしてください。[Microsoft公式ダウンロード](https://dotnet.microsoft.com/ja-jp/download/dotnet/10.0)
2. 更新時は旧版を通知領域の右クリックメニューにある「終了」で閉じます。画面右上の「×」は通知領域への格納です。
3. ZIP全体を別の書き込み可能なフォルダーへ展開し、`CDI-Telopper.exe` を起動します。通常の更新では既存の設定を引き継ぎます。既定のデータ保存先は `%LOCALAPPDATA%\QTelopper\2.x-beta` です。

「バージョン情報」→「保存先」から、`CDI-Telopper.exe` と同じ階層の `Settings` フォルダーを選べます。「保存先を変更」を押し、タスクトレイから終了して起動し直してください。切替先に設定がなければ、変更時点の保存済み設定をコピーします。すでに設定がある場合は、切替先の設定を読み込みます。生データ保存を有効にすると、新しく受信したXML・JSONは選んだ保存先の `raw-reception` に入ります。過去の電文は保存元のフォルダーで参照できます。

通知領域のCDI-Telopperアイコンにマウスを合わせると、現在の受信状態を確認できます。

## 受信と表示の設定

1. 「受信」→「受信元」で、EEW、地震、津波、気象、火山、南海トラフごとにプロバイダーを選びます。使わない種別は「受信しない」を選びます。
2. DMDATA.JPは契約区分に合わせて設定し、APIキーまたはブラウザーでのOAuth認可を用意します。「契約情報を更新」には `contract.list` の権限が必要です。AXISは有効なアクセストークンと対象チャンネルの権限が必要です。[DMDATA.JP設定ガイド](dmdata-oauth.md)
3. 「フィルター」で表示対象の種別・地域・震度条件を、「表示」で字幕レイアウトとページ設定を選びます。「音声」で通知条件と音源を指定します。
4. 「保存して反映」を押し、「テスト」と無音ブラウザープレビューで確認してから「接続」を押します。

「フィルター」→「表示フィルター」の「気象庁以外の震度観測点を非表示」をオンにすると、Wolfx・気象庁XML・DMDATA.JP・AXISの気象庁電文（`jmx-seismology`）による「各地の詳しい震度」で、観測点名の末尾に全角 `＊` が付く地点を字幕から除きます。初期値はオフです。P2P地震情報の観測点はすべてこの設定の対象外です。概要には発表された最大震度を表示し、電文確認の「震度観測点（電文）」では受信した全地点を確認できます。[気象庁の観測点表記](https://www.data.jma.go.jp/suishin/oshirase/pdf/20250703.pdf)

「フィルター」の「気象情報」では、「警報」と「危険警報」を個別に選べます。旧版から更新すると、以前の「警報」のオン・オフを両方に引き継ぎます。

「表示」の「情報種別をバッジではなく字幕で表示」をオンにすると、本番・訓練・テスト・リハーサル・再掲のすべてで、情報種別や震度を字幕として表示します。オフの場合、再掲・訓練・リハーサルは電文確認画面の設定に従います。

「表示」→「ページと文字」の「字幕フォント」で、Windowsにインストール済みのフォントを選べます。「保存して反映」を押すと、ブラウザープレビューとOBSの字幕に適用されます。既定はBIZ UDPゴシックです。選んだフォントに必要な文字がない場合も、既定のフォントで補います。

「ページ秒数」は1ページあたりの表示時間です。地震情報や気象警報・注意報などは、全ページを表示してから自動で消去されます。4秒で3ページなら12秒です。EEWの消去時間は「緊急地震速報（EEW）の自動消去秒」で設定します。

「表示」→「ページと文字」の「電文別のページ秒数」で、震度速報（VXSE51）や震源・震度に関する情報（VXSE53）などの表示時間を個別に設定できます。0の項目は共通の「ページ秒数」を使います。変更は「保存して反映」を押すと、OBS、テスト、再掲にも適用されます。

「出力」→「字幕と一緒に送出する画像」で情報種別を選び、PNGを1枚登録できます。左位置 (X)、上位置 (Y)、横幅は1920×1080を基準にピクセルで指定します。画像は透過と縦横比を保ち、「保存して反映」の後、該当する字幕の表示中だけOBSとブラウザープレビューに表示します。登録できるPNGは2 MB以下、縦横4096ピクセル以下です。

「表示」の「緊急地震速報の継続報で更新された地域名をオレンジ色にする」をオンにすると、同じ警報の前報にもあった地域のうち、予想震度・到達時刻・警報の状態が変わったものを強調します。OBSの横型・縦型とアプリ内プレビューに反映されます。初期値はオフです。

「表示」の「津波注意報以上の発表中は震度速報の定型注意文を省く」をオンにすると、津波情報の表示が有効で、同じ地震の有効な津波注意報・警報を受信済みの場合に、「念のため津波に注意してください。」だけを省きます。地震IDを照合できない場合は注意文を表示します。初期値はオフです。

「表示」の「津波注意報以上の発表中は震度速報を表示しない」をオンにすると、津波情報の表示が有効なとき、同じ地震の震度速報を抑止します。津波注意報・警報が後から届いた場合も、表示中や表示待ちの震度速報を取り下げます。受信内容は電文確認に残り、注意文を省く設定と両方がオンなら非表示が優先されます。津波予報のみの場合や地震IDを照合できない場合は震度速報を表示します。初期値はオフです。

「フィルター」→「表示フィルター」の「南海トラフの定例解説をテロップに表示」は初期値がオフです。テロップに出すには、チェックを入れて「保存して反映」を押します。オフに戻すと、表示中の定例解説を取り下げます。受信した本文は電文確認から読めます。

「受信」→「受信元」の「起動時に受信APIへ自動接続」をONにして保存すると、次回起動時に保存済みの受信元へ接続します。初期値はOFFです。

複数の受信元を使うときは、画面上部に受信元ごとの接続状態を表示します。左側の「接続」欄とタスクトレイでは、各受信元が起動後に再接続待機へ移った回数も確認できます。トレイの表示が長いときは、右クリックして「API別の状態と再接続回数」を開きます。

気象庁XMLは60秒以上の間隔で巡回し、EEWには対応しません。自動切替がONの場合、DMDATA.JP・P2P地震情報・AXISの接続障害が30秒以上続いた対象種別を気象庁XMLで取得し、元の接続が復旧すると戻します。YDITSの本番・テスト受信は一時停止中です。以前YDITSを選択していた場合は、EEWの受信元を「受信しない」として扱います。[対応電文](TELEGRAM_SUPPORT_MATRIX.md) / [提供元と取得条件](data-sources.md)

## OBSとプレビュー

- 「出力」で「OBS Local View」を有効にして保存します。手動登録の場合は「出力」の各OBS用URLを、OBSの地震・EEW・津波・気象のブラウザーソースに登録し、各ソースの「OBSを介して音声を制御する」をONにします。既定のキャンバスは1920×1080です。[OBSソース名と設定](../README.md#obs出力)
- 自動登録する場合はOBS側でWebSocketサーバーを有効にし、CDI-Telopperの「OBS WebSocket 自動登録」にURLとパスワードを設定します。「OBSのブラウザーソースを自動作成・URL更新」をONにして保存し、必要に応じて「今すぐOBSと同期」を押します。
- 「ブラウザープレビューを開く（無音）」で、種別ごとの字幕や、受信済み電文の各ページを確認できます。通知音はOBS側で確認します。手動で登録したOBS用URLは、アプリ再起動後にコピーし直してください。
- 「受信済み電文の個別確認」の「南海トラフの定例解説を表示」で、確認一覧の定例解説を表示・非表示にできます。初期値はオンです。

## 過去電文と訓練

「受信・過去電文を確認」で、受信済み電文の内容と表示結果を確認できます。「取得元と再掲・訓練の表示設定」で、気象庁XML（公式の数日分）、NII、外部JMA XMLファイル、P2P履歴などから取得元を選びます。「過去電文を取得」を押すと一覧に追加します。取得だけでは字幕・音声を送出しません。本番受信中も、「選択した方式で再表示」から「過去情報として紹介」または「本番情報の再掲」を使えます。「本番情報の再掲」は本番で受信した電文向けです。[履歴取得の制約](data-sources.md#manual-history--replay)

操作テスト、履歴リハーサル、テストライブラリーの実行、OBS音声の試聴、Simulatorへの訓練接続は、本番受信を切断してから利用してください。[Simulatorとの訓練接続](disaster-simulator.md)

「テスト」→「生データ・テストライブラリー」の「XMLフォルダーを一括登録」で、サブフォルダー内のXMLも含めて1ファイルずつ訓練ケースに登録できます。登録結果には件数と読み込めなかったファイルが表示されます。一覧は情報種別と電文種別（VPBS50など）で絞り込めます。

同梱サンプルを使うには、ZIPを展開した先にある `TrainingSamples` フォルダーを選びます。気象庁のサンプル電文185件を収録しています。 [出典と利用条件](../jmaxml_20261118_CDI-Telopper/README.md)

## 外部APIを連携する

1. 「出力」で「OBS Local View」を有効にして保存します。「CDI External API v1」で「外部APIを有効化」をONにし、「外部API 接続URLをコピー」で取得したURLを同じPCの連携先に登録します。
2. 再起動後も同じURLを使うには、未使用の固定ポートを指定し、「起動時に外部APIを有効化」をONにして「保存して反映」を押します。「接続キーを保存」を押すと、現在のWindowsユーザー用に暗号化して保存します。
3. ポートを変更した場合や「接続キーを再発行」を押した場合は、新しいURLを連携先に登録します。訓練データには「訓練・リハーサル専用API」とその専用URLを使います。[API仕様と利用条件](external-api-v1.md)

## 不具合の確認と設定の初期化

- 受信できない場合は「受信」の受信元と認証設定を確認し、「ログ」で接続エラーを確認します。受信済みで字幕が出ない場合は「受信・過去電文確認」の表示結果と「フィルター」の条件を確認します。
- 「受信・過去電文確認」で地震電文を選び、「震度観測点（電文）」を開くと、電文に含まれる観測点名と震度を確認できます。地震の細分区域と津波予報区のルビは、読みが特定できたときに確認画面のページ本文に表示します。
- 外部APIがつながらない場合はOBS Local Viewの動作状態、外部APIの有効状態、ポートとキーを確認します。固定ポートを他のアプリが使用中の場合は、別の空きポートを指定します。
- 「バージョン情報」→「設定の初期化」では、確認後に全設定が初期値へ戻り、保存した外部APIキーも消去されます。DMDATA.JPのOAuth認可を取り消す場合は「受信」の「認可を解除」を使用します。
- 問い合わせ前に起動中のバージョンと再現手順を確認します。「ログ」の診断情報を共有する場合は、公開前に接続URL・認証情報・個人情報が含まれていないか確認してください。[不具合報告](https://github.com/black-hawk-bhd/CDI-Telopper-beta/issues)
