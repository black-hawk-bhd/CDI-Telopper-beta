# 緊急地震速報の縦型スタイル

「表示」→「ページと文字」の「緊急地震速報（警報）を縦型で表示」をONにして、設定を保存・反映してください。初期値はOFFで、従来の横型を維持します。「ページと文字を初期設定に戻す」でも横型に戻せます。

- 警報は画面右側の青紫の縦帯に表示します。既存の横型と同じ赤茶の見出し、黄色の震源地・警戒文、白い対象地域、太字ゴシック体を使用します。見出しは「緊急地震速報（気象庁）」で、白い外枠や帯の影は付けません。対象地域は左、見出しと震源地は右の縦書き、警戒文は下部に配置します。
- 独立した2件の警報は横に並びます。続報は対応する帯を更新し、取消は対応する帯だけを更新して、見出しを灰色の取消表示へ変えます。
- 多数の対象地域や長い名前は、帯の中で折り返し・文字サイズ調整を行います。縦型のために対象地域を削除したり、元電文の地名を書き換えたりしません。地域名の地方単位への集約は既存のEEW表示ルールと同じです。
- 北海道内の表示地名が複数ある場合は、利尻・礼文や奥尻島を含め「北海道」1つに集約します。単独の地名は従来表示を維持し、他の地方の集約ルールや受信した地域情報は変更しません。このルールは横型・縦型共通です。
- 予報は従来の横型です。構造化された表示情報を持たない旧データも、本文を失わないよう横型で表示します。
- OBSの緊急地震速報ブラウザソースとブラウザプレビューで同じスタイルを使います。受信済み情報の個別確認には、その情報を登録した時点の表示設定を使用します。
- 本番・訓練・再掲の区分、音声、受信元、表示期限は変更しません。訓練等の上部表示は従来の設定に従って残します。

## 開発時の描画確認

既存の.NETテストに加え、Chromeを使用する描画回帰テストを実行できます。

```powershell
node scripts/verify-eew-vertical.cjs
```

Chromeが標準以外の場所にある場合は、`CDI_CHROME_EXE`に実行ファイルのパスを指定します。使い捨てのブラウザプロファイルとループバック上の模擬ページだけを使用し、実受信・既存ブラウザ・OBSには接続しません。結果と表示例は`artifacts/validation/eew-vertical/`に保存されます。
