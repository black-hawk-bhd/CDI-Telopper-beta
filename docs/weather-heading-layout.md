# 気象系字幕の共通見出し

指定河川洪水予報を除き、バッジは情報種別だけを表示し、その右隣に地名と、電文から確認できる場合のみ状態を表示する。

- 注意報・警報・特別警報の地域一覧：`[大雨警報] 福島県｜継続中`。本文は市町村一覧。発表・継続・解除でページを分ける。
- 警戒説明ページ：バッジは警報種別。地名を右隣に置き、対象項目の状態が一種類の場合のみ併記する。「最大級の警戒」などの説明は本文に残す。
- 気象防災速報（潮位を含む）・竜巻注意情報・記録的短時間大雨情報：バッジと地名を分離し、続きにも同じ見出しを付ける。電文の情報形態が明示された場合は発表・訂正等を併記するが、受信処理が補った項目状態から継続中などを作らない。
- 解除・取消：バッジは情報種別、状態は隣の見出しへ。取消を解除として扱わない。

地名が取得できない電文は地名を推測しない。複数状態の説明ページでは一つの状態に決めつけない。原文の本文は省略・自動要約しない。
プレビューとOBSで同じ構成を使う。見出しは電文確認と読み上げ用テキストにも保持する。
