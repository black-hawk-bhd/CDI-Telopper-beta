旧版を通知領域のメニューから終了し、ZIPを別の書き込み可能なフォルダーへ展開して
CDI-Telopper.exe を起動してください。実行ファイルの横に設定を保存している場合は、
旧版の Settings フォルダーを新版の実行ファイルの横へコピーしてください。

TrainingSamples が付属する版では、「テスト」→「生データ・テストライブラリー」→
「XMLフォルダーを一括登録」で、そのフォルダーを選ぶと訓練ケースに登録できます。
