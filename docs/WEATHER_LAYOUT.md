# 気象情報の段落型レイアウト

気象情報は2行固定を廃止し、上段の見出しと全幅の本文を使用します。
対象は気象警報・注意報、竜巻注意情報、気象防災速報、指定河川洪水予報です。
地震・津波・EEWのレイアウトは変更しません。

- 本文は一文・市町村・対象地区のまとまりを優先します。
- 長文だけを読点などの境界で分割します。電文から取得できた地名と括弧内は保護します。
- 洪水予報は河川名と種別、対象地区ページは観測所・自治体を見出しに残します。
- 表示幅は概算です。フォント倍率、行間、OBSの切り抜き設定によって実際の行数は変わります。
- 非常に長い地名・括弧内は欠落防止を優先し、推奨幅を超えて保持します。
- 自動要約・表現の言い換えは行いません。到達、見込み、おそれなどの原文を保持します。

OBSとWPFプレビューは同じページデータを使用します。電文確認画面も見出しと本文を分離します。
フリガナは電文確認画面だけの補助表示で、読みの正確性・網羅性は保証しません。
