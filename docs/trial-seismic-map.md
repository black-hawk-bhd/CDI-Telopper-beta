# 試験地図（未公開の開発版）

通常・配布ビルドでは無効。関連ボタンはグレー表示され、イベント経由の起動も抑止する。
開発確認時のみ `dotnet build src/EEWTelop.Wpf/EEWTelop.Wpf.csproj -p:TrialMapEnabled=true`
で有効化できる。`scripts/publish.ps1` は `TrialMapEnabled=false` を明示する。
無効状態でもコードと境界データは保持し、描画・配色の単体テストは実行できる。

受信・過去電文確認で地震情報を選択し「試験地図」を開く。表示は選択電文の
スナップショットで、新着受信・一覧の選択変更に追従しない。OBS出力はない。

地図ウインドウの「試験電文を表示（訓練）」をONにすると、内蔵テストライブラリの
地震電文（シナリオの各段階）が一覧に追加される。受信履歴には保存せず、字幕・音声も
実行しない。選択時は地図内に「訓練・試験電文／実際の地震情報ではありません」と表示する。
EEW・津波など地震情報以外の試験電文はこの地図の対象外。

## 外部XMLと受信XML

地図ウインドウの「外部XMLを開く…」から、保存済みの気象庁形式の地震XML（2MiB以下）を1件開ける。
受信契約・接続や履歴設定を変更せず、このウインドウ内だけで表示する。次の外部XMLを開くと置き換わる。
受信履歴への登録・字幕・音声・OBSへの送出は行わない。地図を閉じると読み込み結果を破棄する。
DTD・外部実体は禁止。壊れたXML、地震以外の電文、サイズ超過は拒否し、元の地図を保持する。
訓練・試験のXMLは地図にも訓練表示を付ける。通常のXMLも過去の情報であり最新情報とは限らない。

気象庁XML・AXIS・DMDATAの地震XMLから、観測点コードと所属市町村のコード・名称を保持する。
市町村コード（都道府県も一致）を優先し、未登録コードは明示された市町村名の完全一致で照合する。
観測点の座標ではなく、市町村代表位置に市町村内最大震度を表示する。同じ市町村の観測点は集約される。
観測点情報がない市町村・市町村情報がない地域も、それぞれ取得できた粒度で扱う。
所属市町村が不明な観測点名からの推測は行わず、取得済みの震度地域への集約、または未対応表示とする。

## 地域と表示値

標準配色は陸地が黄緑（#B5CF70）、背景・海域が薄い水色（#D3EDF5）。格子線は淡い青（#B5D8E5）で、表示のON/OFFも選べる。
「配色を変更…」から各色を変更・保存できる。「標準（黄緑・水色）」で標準色へ戻せる。
以前に保存した配色は保持するため、既存環境では同ボタンを選び「保存して反映」を押す。
従来の「ペーパー」「グラファイト」も選択可能。震度情報のある地域は基本の陸地色に震度色を重ねる。

気象庁XMLのObservation配下のArea/CodeとArea/NameをQuakePointに保持する。
地図はコードを優先し、コードがない場合のみ震度地域名を完全一致で照合する。
市町村・都道府県から震度地域を推測しない。不明コードは名前で救済しない。
市町村名と都道府県が完全一致する受信項目は、市町村代表点に震度マーカーを描く。
P2Pの「宮崎都農町」など、都道府県の短縮名を冠した同一市町村名も照合する。
観測点名の前方一致から市町村を推定しない。曖昧・未登録の地点は未対応として残す。
市町村代表点は実際の震度観測点の座標ではない。一覧・地図内にその旨を明記する。
市町村だけの情報から震度地域全体を着色しない。
公式データが同一市の細分区域に分かれている場合は、市町村コード先頭5桁と市名の
一致を確認し、各代表座標の算術平均を市全体の表示用代表点とする（観測点ではない）。

市町村代表座標の出典（2026-09-18取得、1805件）：
- https://www.jma.go.jp/bosai/common/const/area.json
- https://www.jma.go.jp/bosai/common/const/xy.json
- 利用条件：https://www.jma.go.jp/jma/kishou/info/coment.html

`scripts/generate-trial-municipality-points.ps1` で再生成する。
代表位置と市町村名を抽出して加工・同梱し、実行時の外部アクセスは行わない。

同じ震度地域に対応する受信点の最大値を使う。地域全体がその震度で揺れたことを
意味せず、欠測を補間しない。円は代表位置であって観測点ではない。
範囲内の全地点を白縁の円形マーカーで描き、重なっても省略しない。
高震度を手前、選択地点を最前面に描画する。震央はその後に重ねて表示する。
密集箇所では数字が隠れるため、地方図と一覧選択で確認する。地名・位置は動かさない。
右側の全件一覧は震度順で、地図未対応も明示する。
一覧で選択した地域は境界を強調し、ラベル配置を優先する。Mは固定情報欄に表示する。
5?は震度5弱以上と考えられる未入電の区分であり、
震度5強とは区別する。取消では震央と震度を消す。

全国・地方の固定範囲の中から対象地域の図形と震央を含む最小範囲を選ぶ。
範囲外やデータなしでは全国図に戻す。手動選択では範囲外のマーカーを描かない。
海外の震央、EEW、津波・気象の地図表示、リアルタイム更新は対象外。

## 境界データの出典と加工

- 出典：[気象庁 予報区等GISデータの一覧](https://www.data.jma.go.jp/developer/gis.html)
- 対象：[地震情報／細分区域 2024-05-20](https://www.data.jma.go.jp/developer/gis/20240520_AreaForecastLocalE_GIS.zip)
- 利用条件：[気象庁ホームページの利用規約](https://www.jma.go.jp/jma/kishou/info/coment.html)
- 取得ZIPのSHA-256：`92F3C9A51FC0681970672E3E77CB81D9D7885822E55B6CA6AEFCB4EA6D20705F`

気象庁の原データは国土地理院の数値地図・電子国土基本図等を使用して作成されている。
原データの承認番号等は上記出典ページを参照。CDI-Telopperはその境界を加工したもので、
気象庁による制作・推奨・精度保証を意味しない。

JGD2011の座標を地域コード別に統合し、許容差0.003度・トポロジー保持で簡略化。
189地域。離島と内側の穴を保持し、描画はEvenOddで穴を埋めない。
背景地図の輪郭や地域境界には簡略化による誤差がある。

再生成には `scripts/generate-trial-seismic-map.py` とPython、pyshp 3.1.6、
shapely 2.1.2を用いる。引数は展開済みshapefileディレクトリと出力JSONの順。
生成済みJSONを埋め込むため、通常のビルド・利用にPythonやネット接続は不要。
元ZIPや作業用ライブラリは配布対象ではない。

## 検証

WPFのTrialQuakeMapTestsは地域照合、範囲選択、描画フレームを検証する。
EEWTELOP_RENDER_OUTPUTを設定すると確認用PNGを書き出す。確認画像は合成テスト
データであり実際の災害情報ではない。XML正規化テストでも地域コード保持を検証する。
