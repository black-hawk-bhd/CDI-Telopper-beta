# 試験地図（未公開の開発版）

通常・配布ビルドでは無効。関連ボタンはグレー表示され、イベント経由の起動も抑止する。
開発確認時のみ `dotnet build src/EEWTelop.Wpf/EEWTelop.Wpf.csproj -p:TrialMapEnabled=true`
で有効化できる。`scripts/publish.ps1` は `TrialMapEnabled=false` を明示する。
無効状態でもコードと境界データは保持し、描画・配色の単体テストは実行できる。

受信・過去電文確認で地震情報を選択し「試験地図」を開く。表示は選択電文の
スナップショットで、新着受信・一覧の選択変更に追従しない。OBS出力はない。

## 地域と表示値

気象庁XMLのObservation配下のArea/CodeとArea/NameをQuakePointに保持する。
地図はコードを優先し、コードがない場合のみ震度地域名を完全一致で照合する。
市町村・都道府県から震度地域を推測しない。不明コードは名前で救済しない。
P2P等の地域情報を持たない観測点は未対応となり、塗られない場合がある。

同じ震度地域に対応する受信点の最大値を使う。地域全体がその震度で揺れたことを
意味せず、欠測を補間しない。四角は代表位置であって観測点ではない。
混雑時は数字を移動せず、選択地域・高震度・地域コード順に矩形の重なりを判定し、
置けない数字を省略する。震央の周囲は予約領域として保護する。
省略しても着色・右側の全件一覧は残る。一覧は震度順で、地図未対応も明示する。
一覧で選択した地域は境界を強調し、ラベル配置を優先する。Mは固定情報欄に表示する。
5?は震度5弱以上と考えられる未入電の区分であり、
震度5強とは区別する。取消では震央と震度を消す。

全国・地方の固定範囲の中から対象地域の図形と震央を含む最小範囲を選ぶ。
範囲外やデータなしでは全国図に戻す。手動選択では範囲外のマーカーを描かない。
海外の震央、EEW、津波・気象の地図表示、リアルタイム更新は対象外。

## 境界データの出典と加工

- 出典：[気象庁 予報区等GISデータの一覧](https://www.data.jma.go.jp/developer/gis.html)
- 対象：[地震情報／細分区域 2024-05-20](https://www.data.jma.go.jp/developer/gis/20240520_AreaForecastLocalE_GIS.zip)
- 利用条件：[気象庁ホームページの利用規約](https://www.jma.go.jp/jma/kishou/info/coment.html)
- 取得ZIPのSHA-256：`92F3C9A51FC0681970672E3E77CB81D9D7885822E55B6CA6AEFCB4EA6D20705F`

気象庁の原データは国土地理院の数値地図・電子国土基本図等を使用して作成されている。
原データの承認番号等は上記出典ページを参照。CDI-Telopperはその境界を加工したもので、
気象庁による制作・推奨・精度保証を意味しない。

JGD2011の座標を地域コード別に統合し、許容差0.003度・トポロジー保持で簡略化。
189地域。離島と内側の穴を保持し、描画はEvenOddで穴を埋めない。
背景地図の輪郭や地域境界には簡略化による誤差がある。

再生成には `scripts/generate-trial-seismic-map.py` とPython、pyshp 3.1.6、
shapely 2.1.2を用いる。引数は展開済みshapefileディレクトリと出力JSONの順。
生成済みJSONを埋め込むため、通常のビルド・利用にPythonやネット接続は不要。
元ZIPや作業用ライブラリは配布対象ではない。

## 検証

WPFのTrialQuakeMapTestsは地域照合、範囲選択、描画フレームを検証する。
EEWTELOP_RENDER_OUTPUTを設定すると確認用PNGを書き出す。確認画像は合成テスト
データであり実際の災害情報ではない。XML正規化テストでも地域コード保持を検証する。
