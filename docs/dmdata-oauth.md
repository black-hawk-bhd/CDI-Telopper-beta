# DMDATA.JP OAuth2.0設定

beta.55以降のソース版・配布版で利用できます。APIキー方式も引き続き使用でき、既存設定の認証方式は自動変更しません。

CDI-Telopperは公開クライアントの認可コードフローを使用し、PKCE（S256）とstateで認可応答を検証します。クライアントシークレットをアプリへ登録する必要はありません。仕様は[DMDATA.JP OAuth2 v1](https://dmdata.jp/docs/reference/oauth2/v1/)を参照してください。

## 接続手順（通常の利用者）

CDI共通の公開クライアントIDを組み込み済みです。クライアントの新規登録やID入力は不要です。共通なのはアプリを識別する公開IDだけで、利用者のアカウント・契約・トークンは共有しません。

1. CDI-Telopperの受信を停止し、情報種別ごとの受信元をDMDATA.JPへ設定します。EEWの警報／予報区分は実際の契約に合わせます。
2. 「認証方式」で「OAuth2.0（ブラウザー認証）」を選びます。API Base URLは公式の `https://api.dmdata.jp/v2` を使用します。
3. 「ブラウザーで認証」を押し、ご自身のDMDATA.JPアカウントでログインして必要な権限を許可します。認証の待機時間は5分です。「認証を中止」で待機を終了できます。
4. 認証完了後に「保存して反映」を押し、受信を開始します。

## 独自クライアントを使う場合のみ

「詳細設定（独自のOAuthクライアントを使う場合）」を開くとIDを変更できます。空欄・空白のみの旧設定はCDI共通IDに補完します。以前に保存した独自IDは維持し、受信設定の初期化で共通IDに戻します。ID変更後は再認証が必要です。

独自クライアントはDMDATA.JPの認証情報管理で「公開」「認可コードフロー・リフレッシュトークンフロー」として登録し、必要なスコープ、公開URL、利用規約、プライバシーポリシー、連絡先を設定します。リダイレクトURIは `http://127.0.0.1/oauth2/callback` とし、ポートは指定しません。アプリは認証時だけ127.0.0.1の空いているポートで待機します。

## 要求する権限

情報種別の選択に応じて次の権限だけを要求します。権限への同意は契約の代わりにはならず、受信には対象の契約が必要です。

| 選択 | OAuthスコープ |
| --- | --- |
| 共通 | `socket.start`, `socket.close` |
| EEW警報契約 | `eew.get.warning` |
| EEW予報契約 | `eew.get.forecast` |
| 地震・津波・南海トラフのいずれか | `telegram.get.earthquake` |
| 気象情報 | `telegram.get.weather` |
| 火山情報 | `telegram.get.volcano` |

情報種別の追加やEEW契約区分の変更で新しい権限が必要になった場合は、受信を停止して再認証してください。「ブラウザーで認証」で再認証すると既存の認可トークンを失効させ、新しい権限を要求します。

## 更新・保存・解除

アクセストークンの期限が1分以内、または切れた状態でAPI要求を行うと、リフレッシュトークンで更新します。HTTP 401を受けた場合も一度だけ更新して再試行します。WebSocketが正常に接続している間は、トークン更新のためだけに接続を切断しません。

更新要求は同時実行をまとめて処理します。ネットワーク障害・サーバーエラーは再接続の対象です。認可取消やリフレッシュトークン失効の場合は再認証を促し、期限切れトークンで更新を繰り返しません。

アクセストークンとリフレッシュトークンは、設定と同じデータ保存先の `dmdata-oauth.json` にWindows DPAPI（CurrentUser）で暗号化保存します。認証コード・state・PKCE verifierは保存しません。OAuthセッションファイルは設定プロファイルや診断ZIPに含めません。他のWindows利用者へファイルをコピーしても認証は引き継げません。

不要になった認可は、受信を停止して「認可を解除」でサーバー側のトークンを失効させます。解除要求が失敗した場合は保存情報を残して再試行できるようにします。「受信元を初期設定に戻す」だけでは認可解除を行いません。認可の確認・取消はDMDATA.JPの管理画面でも行えます。

従来のAPIキー方式も利用できます。旧設定に貼り付けたOAuthアクセストークンはAPIキーとして使わず、ブラウザーでの認証が必要です。
