# Disaster Simulator 0.3.1 連携（CDI beta.48以降）

CDI-Telopper Disaster Simulator 0.3.1 の Direct Bridge APIを、CDIの訓練入力として利用します。旧OBS-Earthquake Bridge受信元とは別機能です。シミュレーターから直接受信するため、Bridgeは不要です。

## 操作

1. Simulatorで「API起動 / 接続テスト」を実行します。
2. CDIで通常のAPI受信を切断し、「テスト」タブを開きます。
3. Simulator欄へ接続先（既定 `http://127.0.0.1:64270/`）とトークン（Simulatorの既定 `cdi-sim-test`）を入力します。コピーURLの `/api/v1/status?token=...` は入れず、トークンは専用欄に分けます。
4. 「訓練接続」を押し、OBSにも訓練字幕・音声を出力する確認を承認します。
5. 接続済みになってからSimulatorで再生、選択電文送信、または架空シナリオ送信を実行します。
6. 終了時は「切断・訓練表示消去」。本番受信は自動再開しません。接続欄から手動で再開してください。

## 動作と制限

- 地震の震源・最大震度・震度地点、EEWの予報/警報、津波予報地域・沿岸観測点・高さ等を既存の字幕機能へ変換します。SimulatorがAPIへ出力しない内容（VXSE61、詳細な長周期情報等）は補えません。
- **内部では必ず訓練として扱います**。Simulator側で訓練表示をOFFにした実電文リプレイも、本番には変換しません。通常は全ページに訓練バナーを表示します。以下の隠し操作で、セッション中だけバナーを非表示にできます。
- 本番受信と同時接続しません。本番履歴・本番の外部API状態へ登録しません。外部プラグインにも同じ訓練を渡したい場合は、プラグインからSimulatorへ直接接続してください。
- 初回スナップショットは基準状態として読み込み、字幕・音声を再実行しません。同じ内容の定期通知でも再実行しません。接続後に新たに送信してください。
- 取消・期限切れは該当種別の訓練表示を消去します。津波警報等の解除は解除字幕として表示します。現在は同種別の訓練表示をまとめて消去するため、複数地震の同時取消を個別に再現する用途には制限があります。
- Simulatorの状態クリア（セッション変更）を受けると訓練状態を初期化します。0.3.1は空状態を即時配信しないため、取消通知または次の定期通知（最大約15秒）で反映します。
- 接続切れ・応答停止時は訓練表示と音声を消去し、自動再接続しません。状態を確認して手動で接続してください。
- 同一PCのIPリテラル・HTTP接続に限定し、認証情報は保存しません。プロキシ・HTTPリダイレクトは使用しません。
- 地図機能は復活させません。添付Simulatorの実行ファイルの自動起動や書換えも行いません。

接続中は他のテスト・過去電文再表示を併用せず、実配信で訓練情報を誤送出しないようOBS側の状態も確認してください。

## 本番同様のリハーサル表示（隠し操作）

Simulator接続済みの状態でCDIの操作ウインドウを選択し、**Ctrl＋Shift＋Alt＋R** を押してください。警告に同意すると、Simulatorからの新着に限りプレビュー・OBSの訓練バナーを非表示にします。同じキーでもう一度押すと通常に戻ります。

- 切替時は字幕・音声を消去します。Simulatorから対象電文を再送信してください。
- 操作画面には非表示モードの警告が残ります。切断・通信エラー・アプリ終了で解除し、設定保存や次回接続へ引き継ぎません。
- 訓練区分、本番受信との排他、本番履歴・外部APIへの混入防止は変更しません。他のテスト・過去電文のバナーには適用しません。
- 本文の「【訓練】」は書き換えません。Simulator側が付ける接頭辞も不要な場合は、Simulatorの訓練表示をOFFにして送信してください。それでもCDI内部では訓練扱いです。
- 表示だけでは本番と区別できなくなるため、非公開リハーサルで使用し、配信・録画・送出先を必ず確認してください。
