CDI-Telopper 2.0.0-beta.74 操作ガイド
Windows 10 / Windows 11（64ビット）

旧版を終了し、新しいZIPを別のフォルダーへ展開して CDI-Telopper.exe を起動してください。
フォルダー版と単一EXE版は .NET 10 を同梱します。

【字幕フォント・表示時間】
「表示」→「ページと文字」で、字幕フォントと電文別のページ秒数を選べます。
電文別の秒数が0の項目には共通の「ページ秒数」を適用します。
自動消去する字幕は全ページを表示してから消えます。EEWの消去時間は専用設定に従います。

【津波注意報・警報と震度速報】
津波情報の表示を有効にして「津波注意報以上の発表中は震度速報を表示しない」をオンにすると、
同じ地震の有効な津波注意報・警報がある場合に震度速報を非表示にします。初期値はオフです。
受信した震度速報は電文確認から参照できます。変更後は「保存して反映」を押してください。

【設定・受信電文の保存先】
「バージョン情報」→「保存先」で、実行ファイル横の Settings フォルダーを選べます。
保存先の変更は次回起動から適用し、以降に保存する受信XML・JSONも対象です。
実行ファイル横に保存している場合は、旧版の Settings フォルダーを新版の実行ファイルの横へコピーしてください。
