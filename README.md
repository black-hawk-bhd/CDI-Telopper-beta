# CDI-Telopper — CDI-テロッパー


[English](README_EN.md) | 日本語

Comprehensive Disaster Information Telopper（CDI-Telopper）は、地震・津波・気象・火山・南海トラフに関する防災情報を受信し、OBS向け字幕として出力するWindowsアプリです。

現在の公開版は **2.0.0-beta.57** です（2026年10月4日）。開発中のベータ版であるため、本番配信へ導入する前に、利用環境で受信、再接続、OBS出力、音声、取消・解除を十分に確認してください。CDI-Telopperは気象庁の公式ソフトではありません。
本ソフトウェアだけを防災判断の根拠にせず、必ず気象庁などの公式情報も確認してください。

### フリガナ機能の注意事項

**フリガナは読み上げの補助であり、読みの正確性・網羅性を保証するものではありません。配信で読み上げる前に、自治体などの公式情報で正式な読みを確認してください。** 日本郵便の都道府県・市区町村データを用いるため、予報区・海域・海外地名・旧地名などは未対応の場合があります。同名地名の文脈や表記によっては誤った一致・読みが生じる可能性があります。読みを特定できない地名は原則としてルビを付けません。OBS字幕・再掲・音声には反映しません。

beta.37では、AXISなどのXMLで届く大規模噴火の遠地情報について、不要な地震用定型3ページを省略し、噴火本文から表示するよう修正しました。潮位観測・津波到達予想は全文を保持します。配布文書からウイルス対策の除外設定に関する案内も削除しました。

## 対応する主な情報

| 分類 | 主な対応内容 |
| --- | --- |
| EEW | P2P EEW、VXSE43、警報を含むVXSE45、AXIS `eew`、Wolfx JMA EEW |
| 地震 | VXSE51、VXSE52、VXSE53、VXSE62、VYSE60、P2P地震情報、Wolfx JMA地震情報 |
| 津波 | VTSE41、VTSE51、VTSE52、P2P津波情報 |
| 気象 | VPWW55～61、VPWS50、VPBS50・51、VPHW50・51、VXKO50～89（受信元による） |
| 火山 | VFVO50、VFVO56 |
| 南海トラフ | VYSE50 |

VPOA50の解析機能は過去電文等のために残していますが、気象庁XML・AXISの新着受信では除外します。DMDATAの受信設定は変更していません。

配信元から届くすべての電文を字幕化するわけではありません。選択外の受信元、対応外電文、警報条件を満たさないEEW、表示フィルターで除外された情報、破損・重複・古い電文などは表示されない場合があります。

気象警報・注意報では、表示フィルター適用後の内容が直前の同一電文系列と変わらない場合、字幕と音声を再実行しません。受信・過去電文確認には電文を保存し、「表示対象の変更なし」と表示します。

また、表示フィルター適用後に残る項目がすべて「継続」の場合は、既定では字幕と音声を実行しません。新規発表・更新・解除は通常どおり表示され、この動作は「継続中の項目しかない電文を表示しない」チェックボックスで変更できます。気象防災速報（VPBS50/51）の音声は、通常の気象警報・注意報とは別に有効化して音源を指定できます。

EEW音声はすべての地震・津波・気象音声より優先されます。EEW受信時は待機中の気象音を破棄し、再生中の対象音をEEW音で割り込みます。EEW音の再生が完了するまでに届いた地震・津波・気象音声は再生しません。

受信・過去電文確認から再表示する際は、用途を3方式から選べます。「本番情報の再掲」の識別バッジは電文の発表日時のみを表示し、「過去情報」「動作訓練」では用途と発表日時を表示します。履歴元から取得した過去電文は「本番情報の再掲」を選べず、本番で受信した電文だけが本番再掲の対象です。

## 受信プロバイダー

### 気象庁XML（PULL型・直接取得）

気象庁が公開するXML電文を直接取得する、認証不要の受信元です。

- 対象：本ソフトが対応する地震・津波・気象（指定河川洪水予報を含む）・火山・南海トラフ情報。**EEWは対象外**です。
- 設定：情報分類ごとに「気象庁XML（60秒巡回・遅延あり）」を選び、「保存して反映」を押します。この手動選択とは別に、beta.47以降は上記の接続障害時の自動代替にも対応しています。
- 巡回：前回の巡回開始から60秒以上の間隔を維持します。気象は `extra.xml`、地震・津波・火山・南海トラフは共通の `eqvol.xml` を各巡回で1回ずつ確認します。複数分類で選択しても同じフィードを重複巡回しません。新着の本文は別途取得します。
- 除外：`VPWW53`・`VPWW54`・`VPOA50` は取得しません。取得済みURLは保持範囲内で重複取得を防ぎ、失敗した取得は次回巡回で再試行します。
- 制限：掲載遅延・停止があります。接続前の電文は新着として表示せず、長時間停止中の欠落をすべて補完するものでもありません。「接続済み」は巡回成功を示し、新着や字幕表示を保証しません。

[気象庁XMLの取得方法・利用上の注意](https://xml.kishou.go.jp/xmlpull.html)

### P2P地震情報 API

主にEEW、地震情報、津波情報で利用します。ProductionとSandboxを選択できます。

P2P地震情報 APIは気象庁が運営する公式APIではありません。気象庁発表情報を扱う外部サービスとして、公式情報と併用してください。提供元の利用条件、レート制限、二次利用条件も確認してください。

https://www.p2pquake.net/develop/

### DMDATA.JP

利用者自身の契約と、APIキーまたはOAuth2.0による認可が必要です。EEWは契約に合わせて警報契約（VXSE43）または予報契約（VXSE45）を選択します。予報契約では、警報を含むVXSE45と取消を字幕対象とします。気象庁発表情報を扱う外部サービスとして、公式情報と併用してください。料金は有料です。

beta.55以降では、APIキーに加えてOAuth2.0のブラウザー認証を利用できます。CDI共通の公開クライアントIDを組み込み済みのため、通常はID入力・クライアント登録が不要です。「認証方式」でOAuth2.0を選び「ブラウザーで認証」を押し、ご自身のアカウントで許可します。トークンはWindows利用者ごとに暗号化保存し、再接続等のAPI要求時に期限が近ければ自動更新します。接続方法・必要権限・認可解除は[OAuth設定手順](docs/dmdata-oauth.md)を参照してください。

beta.56以降は「受信」の「契約情報を更新」で契約情報を手動取得できます。APIキーには `contract.list`、OAuthには同権限の追加認可とクライアント登録側の許可が必要です。共通クライアントの登録状態は未確認のため、契約情報取得の成功を保証しません。通常の受信認可の要求権限は変更していません。

※法人向けの方は法人向けプランの契約が必要です。

https://dmdata.jp/

### AXIS

試験的プロバイダーです。APIは気象庁が運営する公式APIではありません。気象庁発表情報を扱う外部サービスとして、公式情報と併用してください。利用者自身が取得した有効なアクセストークンと、利用するチャンネルの契約が必要です。`eew`、`jmx-seismology`、`jmx-meteorology`、`jmx-volcanology`を、選択した情報分類に応じて使用します。

※非商用に限り無料で利用できます。商用利用はできません。

https://axis.prioris.jp/

### Wolfx

認証不要の公開WebSocket APIです。EEWと地震情報の受信元として選択できます。EEWでは警報・取消のみを字幕対象とし、予報のみの更新は表示しません。

**注意：Wolfxの地震情報は、現在はVXSE53相当の「震源・震度情報」のみです。** 震度速報（VXSE51）、震源に関する情報（VXSE52）、長周期地震動に関する観測情報（VXSE62）などはWolfxから取得できません。地震情報は配信された一覧の最新項目を取り込み、既存のイベントID重複判定を適用します。

Wolfx APIは政府機関・気象機関が運営する公式APIではありません。本ソフトだけを防災判断の根拠にせず、気象庁などの公式情報を併用してください。利用規約、接続数、再配信条件は提供元で確認してください。

https://wolfx.jp/docs/open-api/

DMDATA.JPとAXISの認証情報はWindows DPAPI CurrentUserで暗号化して保存します。認証情報をソース、配布ZIP、ログ、診断ZIPへ平文で含めない設計です。

## OBS出力

指定河川洪水予報（VXKO50～89）は「気象情報」で受信・表示します。河川の見出し、観測所別の浸水想定地区、レベル4・5の主文を順に表示し、2行固定を廃止し、見出しと本文を分離します。レベル2は注意報、3・4は警報、5は特別警報の表示・音声設定を使用するため、注意報を非表示にしている場合はレベル2も表示されません。

beta.57以降はOBSへ次の4つのブラウザーソースを登録します。各ソースは1920×1080を前提とします。

- CDI-Telopper 地震字幕
- CDI-Telopper 緊急地震速報
- CDI-Telopper 津波字幕

beta.57以降は、地震・EEW・津波・気象の音声をそれぞれ該当ソースへ出力します。各ブラウザーソースで「OBSを介して音声を制御する」を有効にしてください。OBS WebSocket自動同期では、4ソースの音声制御を有効にし、旧「CDI-Telopper 地震字幕・全ての音声」を「CDI-Telopper 地震字幕」へ改名してURLを更新します。旧ソースと新ソースを重複登録しないでください。配布版beta.56は従来の地震ソースへの全音声集約です。

試聴も該当種別のソースで再生します。その種別のソースが未接続なら送信せず、ログに記録します。ブラウザープレビューは引き続き無音です。音声停止は全ソースに適用され、EEW受信時は他種別の音声を停止する優先制御を維持します。各ソースのモニターは自動同期で「モニターオフ」に設定します。

旧OBS地図出力と常時デスクトップオーバーレイは廃止済みです。内蔵試験地図も廃止しました。PC上での確認にはブラウザープレビューと「受信・過去電文を確認」ウインドウを使用します。

## 動作環境

- Windows 10またはWindows 11（64ビット）
- OBS Studio 28以降を推奨
- 利用する受信プロバイダーへ接続できるインターネット環境
- AXISまたはDMDATA.JPを使う場合は、有効な契約と認証情報

GitHub Releasesの配布物は.NET 8自己完結型です。通常利用ではVisual Studioや.NET SDKをインストールする必要はありません。

## インストールと初回起動

1. [Releases](https://github.com/black-hawk-bhd/CDI-Telopper-beta/releases)からZIPをダウンロードします。
2. 必要に応じて`SHA256SUMS.txt`と照合します。
3. ZIP内から直接実行せず、書き込み可能な通常フォルダへ完全に展開します。
4. `CDI-Telopper.exe`を起動します。
5. 情報分類ごとの受信元、認証情報、OBS、音声、表示条件を設定します。
6. テスト表示を確認してから「接続」を押します。

多重起動は抑止されます。ウインドウ右上の「×」では完全終了せず、タスクトレイへ格納されます。完全終了する場合は、タスクトレイの右クリックメニューから「終了」を選択してください。

設定、状態、ログは互換性維持のため、既定では`%LOCALAPPDATA%\QTelopper\2.x-beta`へ保存します。保存先を変更する場合は`QTELOPPER_V2_BETA_DATA_DIRECTORY`を使用します。

## ブラウザープレビューモニター（beta.52）

「出力」でOBS Local Viewを有効にして保存後、操作画面の「ブラウザープレビューを開く（無音）」を押してください（配布済みbeta.56以前のボタン名は「ブラウザーモニターを開く（無音）」、beta.55以前の設定タブは「表示・出力」）。Chromeを優先し、見つからない場合は案内後に既定ブラウザーで開きます。外部APIの有効化は不要です。beta.57以降は旧WPFプレビューを廃止し、このブラウザー画面に統一しています。

- 地震・火山、EEW、津波、気象の4出力を並べて確認できます。見出しをクリックすると拡大します。OBSと同じ描画処理・出力設定を使用します。
- 下部の受信済み電文一覧（この起動中に確認画面へ登録された最新500件）から、同じ種別の複数電文も個別確認・ページ送りできます。字幕や音声は再送出しません。
- 常に無音で、OBSの音声接続数に加算しません。本番／訓練、表示終了、受信接続状態、モニター更新停止を表示します。
- 地震と火山は従来の共通出力枠です。各枠はその出力の現在の1プログラムを表示し、すべての過去電文を同時送出する機能ではありません。OBSアプリ自身の合成結果・配信状態を取得する機能でもありません。
- ローカル専用です。接続URLにはOBS用の認証キーを含むため公開しないでください。接続停止時の表示は最後に確認した内容です。

## 地震の表示フィルター（beta.57）

「フィルター」タブで設定し、「保存して反映」してください。

- 「表示しない地震の最大震度」は震度1・2・3・4・5弱・5強・6弱・6強を個別に除外できます。地震全体の最大震度で判定し、地点ごとの除外設定ではありません。震度7・震度不明・5弱以上未入電・取消情報はこの震度フィルターで除外しません。旧「最大震度2以下を非表示」は震度1・2の選択へ引き継ぎます。
- 「地震の対象地域」は複数の都道府県を選択できます。全国が初期値で、「対象の地震と地点一覧の両方」「対象の地震だけ（地点一覧は全国）」「地点一覧だけ（地震はすべて表示）」から選べます。地域の判定には受信した震度地点・長周期地震動の地域を使います。震源のみ・遠地・地域を判定できない情報や取消は地域設定で除外しません。概要の最大震度は全国の受信値を保持します。
- 「最大震度3以上の地震でも、震度1・2の地点を表示する」は初期OFFです。ONで受信済みの低震度地点も表示しますが、地域の地点絞り込みは維持します。震度速報など電文に含まれない地点は補完しません。
- EEW・津波のフィルター、音声の震度しきい値、外部APIの元データ、本番／訓練区分は変更しません。

## 新規発表時の音声（beta.57）

「音声」タブの「音声を鳴らすタイミング」を地震・津波・気象ごとに選び、「保存して反映」してください。初期値は従来方式です。音声ファイルと再生対象の階級は引き続き個別に設定します。

- **従来方式**：既存の階級別・電文別の音声判定を維持します。
- **最初の新規発表のみ**：同じ地震、津波の発表継続中、同じ発表元・気象種別の継続中では初回のみ対象にします。格上げと対象地域の追加は鳴らしません。全解除後の新しい発表は再び対象になります。
- **新規発表＋格上げ・対象地域追加**：初回に加え、警報の格上げや新しい対象地域の追加も対象にします。気象は新規・格上げの項目だけから音声を選び、別の継続中の特別警報があるだけではその音声を選びません。

新規方式では、継続・同レベル更新・訂正・解除・津波観測更新・自動再掲では鳴らしません。非表示・ミュート中の受信も判定の基準として記録します。判定状態はこの起動中のみ保持し、本番・サンドボックス・訓練・履歴リハーサルを分離します。気象は地域・警報種別・状態、津波は予報区域の警報段階、地震は発生時刻（不明時はイベントID）・最大震度・震度3以上の地域を比較します。接続前からの発表かどうかを判断できない情報は、最初に受信した状態を基準にするため、実際の初回発表を完全に保証する機能ではありません。電文がない地点や発表状態は推測しません。

EEWの初報・続報・取消の設定、OBS試聴、音声の同時受信まとめ、EEW音声の優先制御は維持します。
