# OBS-Earthquake Bridge 連携（開発版）

## API 1.1 / fixed-r8 対応

`obs-earthquake.bridge.event.v1` と旧 `cdi.bridge.event.v1` を受信可能。r8のschema/type省略スナップショット、入れ子の震源、津波メタデータ＋payload、各種 `.cancel` 通知を読み分ける。CDIの外部公開APIの仕様は変更しない。

`upstreamHealthy` / `upstreamState` / feedの `configured`・`stale` を接続判定へ反映。通信障害や `available:false` は解除と解釈しない。mode不明のr8初期情報は本番採用しない。

予報・観測は独立した報番号で管理し、同一EventIDでも観測の取消で予報を消さない。異なるEventIDの津波観測は同一予報と組み合わせて外部APIに公開しない。期限切れは保持するが新着字幕・音声を出さない。未知typeはその通知だけ無視する。

添付仕様の津波 `payload: {}` は内容の省略例のため、具体的な地域・高さは生成しない。津波本体は従来のJMA互換 `Head` / `Body.Tsunami` を読み込む。本文なしの取消はメタデータから判定する。r8実機との接続確認は別途必要。

## 接続方向と設定

1. OBS-Earthquake Bridgeを同じPCの `http://127.0.0.1:51235/` で起動する。
2. CDIの受信元で、必要なEEW・地震・津波を「OBS-Earthquake Bridge（ローカル連携）」に変更し、保存して接続する。未選択の種別は通常の受信元を使う。
3. CDIから他のソフトへ提供する場合のみ、別途「CDI External API v1」をONにする。

BridgeのSSE `/api/v1/events` とCDIのWebSocket `/api/v1/events` は、**別サーバー・別仕様**。同じURLへ接続してはいけない。

上流の接続状態はBridgeのstatusを30秒間隔で確認する。SSEの接続が生きていても上流が切れていればCDIはStale（更新停止）として扱い、警報解除には変換しない。

Bridge → CDIの受信は、複数の情報種別を選んでも1接続。認証情報はBridge側で管理し、CDIへdmdataキーをコピーしない。ループバック固定、プロキシ・リダイレクトを無効化する。

初期同期はSSE接続後に現在情報を取得し、その間の通知を後から処理する。初期・再接続の取得結果は状態のみ更新し、字幕・音声は出さない。通常の新着だけ既存の表示フィルター・重複判定・EEW優先処理を通す。HTTP/SSEエラーは解除に変換せず、2～30秒で再接続する。無通信60秒で接続を張り直す。読込上限4 MiB、待ち行列256件（満杯時に古い警報を捨てない）。

## 添付r6の互換制限と修正

添付r6は新着の通知には `mode` があるが、地震・津波の現在情報には訓練区分が残らない。CDIはこれらの**区分不明な初期スナップショットを採用しない**。EEWは自身の訓練フラグも確認する。通常の新着は受信できる。

また、津波変換時に電文取消と有効期限が失われる。空配列だけでは「取消」「解除」「未取得」を区別できないため、空データを警報解除として扱わない。

同梱 `bridge-r6-metadata.patch` は、r6のGoソースに以下の追加フィールドを保持する互換修正：

- 地震・津波payloadに `mode: live/test`。
- 津波 `Head.InfoType`（電文取消を保持）。
- 津波 `Head.ValidDateTime`（入力に存在する場合）。

パッチはZIP展開先の `bridge/src/main.go` に適用し、Bridgeを再ビルドして使う。既存HTMLのフィールドを削除・変更しない。**このリポジトリ内に修正版Bridge EXEは含まれない。GoでのビルドとBridge実機確認は別途必要。** 原本ZIP・原本EXEは変更していない。

パッチ適用後でも、Bridgeが取得・変換しない情報（沖合津波観測VTSE52、地震の津波判定など）は補完できない。CDIは未知値を「津波なし」にしない。Bridgeの接続・上流状態と発表日時を確認し、公式情報と併用する。ソフトを両方後から起動した場合、Bridge自体が過去・現在情報を取得できなければCDIにも情報は来ない。

## CDI共通API

CDIが公開するデータはBridgeのJSON形式ではなく、受信元に依存しない地震・EEW・津波スナップショット。詳細は [共通API仕様](../../docs/external-api-v1.md)。表示色やプラグイン専用HTML、レイアウトをAPIに含めない。

Bridge接続のためにCDIの外部APIをONにする必要はない。外部APIをONにしても受信元がBridgeへ自動変更されることはない。
