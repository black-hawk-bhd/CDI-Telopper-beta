CDI-Telopper 2.0.0-beta.69 操作ガイド
Windows 10 / Windows 11（64ビット）

旧版を終了し、新しいZIPを別のフォルダーへ展開して CDI-Telopper.exe を起動してください。
フォルダー版と単一EXE版は .NET 10.0.14 を同梱します。

【Wolfxの受信設定】
「受信」→「受信元」で「津波情報」または「南海トラフ等」の受信元にWolfxを選び、「保存して反映」を押してください。
地震情報の受信元にWolfxを選ぶと、各地の震度詳細も取得します。受信した観測点名と震度は「受信・過去電文を確認」の「震度観測点（電文）」で確認できます。
YDITSの受信は一時停止しています。旧版でYDITSを選んでいた項目は「受信しない」として読み込まれます。

【緊急地震速報（警報）の続報音声】
画面に表示する対象地名が変わったときに続報音声を再生します。報番号や震度だけが更新された場合は再生しません。
