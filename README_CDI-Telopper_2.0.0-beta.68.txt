CDI-Telopper 2.0.0-beta.68 操作ガイド
Windows 10 / Windows 11（64ビット）

旧版を終了し、新しいZIPを別のフォルダーへ展開して CDI-Telopper.exe を起動してください。
フォルダー版と単一EXE版は .NET 10.0.14 を同梱します。

【受信APIへの自動接続】
「受信」→「受信元」で「起動時に受信APIへ自動接続」をONにし、「保存して反映」を押してください。
次回起動時に保存した受信元へ接続します。初期値はOFFです。
複数の受信元を使う場合は「接続」欄やタスクトレイで、受信元ごとの状態と再接続回数を確認できます。

【本番受信中のテストと再表示】
操作テスト、履歴リハーサル、テストライブラリーの実行、OBS音声の試聴、Simulator接続は、本番受信を切断してから利用してください。
「受信・過去電文を確認」の「本番情報の再掲」と「過去情報として紹介」は、本番受信中も利用できます。
