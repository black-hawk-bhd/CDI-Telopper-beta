# CDI-Telopper用 訓練XML

気象庁が公開するサンプルデータから、CDI-Telopperが読み込めるXMLを185件選びました。XMLは原文のまま、情報種別と電文コードごとのフォルダーに収録しています。

CDI-Telopperの「テスト」→「生データ・テストライブラリー」→「XMLフォルダーを一括登録」で、このフォルダーを選ぶと、全件を訓練ケースに登録できます。表示はフィルターや電文の有効期限、先行する電文の有無に左右されます。

| 情報種別 | 件数 |
| --- | ---: |
| 緊急地震速報 | 33 |
| 地震情報 | 54 |
| 津波情報 | 34 |
| 気象情報 | 57 |
| 火山情報 | 7 |

出典は気象庁ホームページの「気象庁防災情報XMLフォーマット 技術資料」掲載のサンプルデータ（2026年11月18日一部更新）です。 [配布元](https://xml.kishou.go.jp/tec_material.html)

XMLには気象庁のサイト利用規約と公共データ利用規約（第1.0版）が適用されます。 [気象庁の利用規約](https://www.jma.go.jp/jma/kishou/info/coment.html) ・ [公共データ利用規約（第1.0版）](https://www.digital.go.jp/resources/open_data/public_data_license_v1.0)
