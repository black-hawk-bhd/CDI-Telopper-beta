CDI-Telopper 2.0.0-beta.65 操作ガイド
Windows 10 / Windows 11（64ビット）

旧版を終了し、新しいZIPを別のフォルダーへ展開して CDI-Telopper.exe を起動してください。
フォルダー版と単一EXE版は、いずれも .NET 10.0.14 を同梱します。
通常の更新に設定の初期化は不要です。

【YDITSの一般向け緊急地震速報（警報）】
「受信」→「受信元」→「EEW」で「YDITS（一般向け警報・ベータ）」を選択し、保存します。
認証情報は不要です。取得間隔は1秒以上で、障害時は公式の代替先を順に試します。
警報対象地域の表示と、照合情報のない取消報の反映には対応していません。
「YDITS（テストモード）」の電文は、ブラウザーモニターの「受信済み電文の個別確認」で
訓練として確認できます。OBSへの字幕・音声の自動送出や、本番APIへの反映はありません。
YDITS実APIの応答は確認環境で取得できず、模擬応答で検証しています。
YDITS公式仕様 https://www.ydits.net/api/vxse43/

【緊急地震速報の音声】
同じ警報の続報音声は、OBSから再生終了通知を受けた後に順次再生します。
取消報では待機中の続報を破棄し、設定した取消音声が割り込みます。

【外部API】
地震観測点の points[].address に受信元の地名を追加しました。name は従来の表示名です。
詳細は同梱の EXTERNAL_API_V1.md を参照してください。
